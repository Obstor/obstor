# Obstor Backend
Obstor Backend adds S3 and [other supported protocol](/docs/protocols) compatibility to third-party cloud storage providers.

## Supported Backends
- [NAS](/docs/backend/nas)
- [S3](/docs/backend/s3)
- [SFTP](/docs/backend/sftp)
